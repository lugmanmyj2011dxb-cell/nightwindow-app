# 这是给"以后的宗教向 App"用的参考代码，不属于眠窗这个项目

眠窗最终定位是世俗化、大众向的助眠白噪音 App，静修朗读（古兰经/圣经）这个功能已经从
主项目里完全移除（`www/index.html` 里的相关 HTML/CSS，`www/js/` 里的脚本引用都拿掉了），
不会出现在打包出去的安装包里。

这里留着的 `faith-readings.js`，是当时搭好的播放器骨架（独立于环境音混音器、点播即停、
带署名展示位），以后如果要单独做一个宗教向的 App，可以直接拿这份代码当起点，省得重写。

## 还有一样东西留在主项目里，没有跟着搬过来

`www/js/i18n.js` 里其实还留着 16 种语言的 `groupFaith` / `faithNote` / `faithQuranTitle` /
`faithBibleTitle` / `faithPending` / `faithAttribution` 这几个翻译词条——没有删，因为它们
不会被任何界面引用，纯粹是静静地待在字典里，不影响眠窗现在这个 App 的任何行为。以后真要
做宗教向 App 时，直接去眠窗项目的 `www/js/i18n.js` 里搜这几个字段名，把对应的翻译抄过去
就行，不用重新翻译一遍 16 种语言。

## 提醒（原来那份分析里最重要的两条，抄一遍避免以后忘掉）

1. 古兰经/圣经的**诵读录音**本身是有独立版权的，跟经文文字是两回事，正式做之前要把每一段
   音频的授权来源核实清楚，尤其如果是收费 App。
2. 千万别用语音合成/AI 生成诵读或朗读内容——这是信众社群公认的底线，真实用户评论原话是
   "宗教语境里 AI 诵读怎么错都不为过"，踩这条大概率是砸自己招牌，不是加分项。

完整的市场分析和执行建议，存档在眠窗项目根目录 `商业化与全球上架方案.md` 的"七、静修朗读
功能"这一节里，以后要用可以直接回去翻。
