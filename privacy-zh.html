感谢你使用"眠窗"（以下简称"本应用"）。我们非常重视你的隐私，本政策说明本应用如何处理你的信息。

本应用是否要求注册

不强制。核心的白噪音播放、场景切换、定时器等功能完全不需要注册或登录，这些设置只保存在你的设备本地，不会上传到任何服务器。只有当你希望"更换手机/平板后，会员资格和自定义组合能自动找回"时，才需要登录一个账号——这是可选功能，不是使用门槛。

⚠️ 当前版本说明：登录/账号功能（包括下面「如果你选择登录」「账号注销」两节描述的能力） 目前还在开发中，尚未在应用内上线——你现在使用的版本里找不到"登录"入口，也不会被要求登录。 这两节描述的是账号功能上线后将遵循的数据处理规则，先写在这里是为了让你在它上线的第一天就 能查到完整说明，不代表现在就能用。账号功能正式上线时，我们会更新这条说明。

如果你选择登录，我们收集哪些信息

我们只收集能证明"这是你本人"的最少信息，不会要求你上传身份证、人脸或其他政府发放的证件：

  • 邮箱地址 或 手机号码（二者至少一个）——用于接收验证码登录，证明这个邮箱/手机号确实由你本人操作；
  • 如果你选择用 Google / Apple / Facebook / LINE / 微信登录，我们只会拿到该平台返回的一个不可读的身份标识（类似一串乱码），不会读取你的真实姓名、头像、好友列表等信息；
  • 你在应用内生成的使用数据（会员到期时间、自定义混音组合、连续使用天数等），用于在你换设备后把这些找回来。
  • 如果你是钻石💎版会员并使用"心愿点单"功能，你在邮件里写的内容会通过你自己的邮件客户端发送到我们的钻石专属客服邮箱——这是你主动发送的邮件，不是本应用自动收集的信息，我们只用它来评估是否开发你想要的声音/场景，不会关联到你的其他身份信息做别的用途。钻石专属主题的选择，和其他本地设置一样，只保存在你的设备本地，不会上传。

我们不会把上面这些信息和你的身份证号、人脸、住址等强身份信息关联，也不会要求你提供这些信息才能使用会员功能。大陆手机号在办理时本身已由运营商完成实名登记，这是国家对手机号的统一要求，不是本应用额外收集或处理的信息。以上收集范围遵循《个人信息保护法》第6条"最小必要原则"和《网络交易监督管理办法》第十三条"合法、正当、必要"原则——我们不会用一次性概括授权、默认授权或者和其他授权捆绑的方式，让你在不知情的情况下同意收集本不必要的信息。

欧盟/英国/欧洲经济区用户的数据权利（GDPR）

如果你在欧盟、英国或欧洲经济区，除了下面「账号注销」提到的删除权，你还可以随时联系我们行使： 查阅我们持有的关于你的个人信息（访问权）、要求更正不准确的信息（更正权）、要求以可携带的格式 导出你的数据（数据可携权）、对我们处理你信息的方式提出异议、以及撤回你此前给过的同意（撤回 同意不影响撤回前已经进行的处理）。我们会在收到请求后的合理期限内响应。

购买/订阅时的支付信息

你的付款在 App Store / Google Play / 微信支付 / 支付宝 / Stripe 的页面内完成，本应用不会接触、也无法看到你的银行卡号或支付账户密码。我们只会从这些平台收到一个"这笔订单确实支付成功"的回执（订单号、金额、时间），用来给你解锁对应的会员权限。

账号注销

你可以在"账号设置"里随时申请注销账号，我们会在确认申请后的合理期限内删除你的邮箱/手机号/第三方登录标识等账号信息；法律要求保留的交易记录（如购买收据）会按相应法规的最短期限保留后删除。注销不会影响你已经购买的权益在对应应用商店（Apple/Google）账号下的记录——那部分记录由对应商店保管，不受本应用的注销流程影响。

只保存在你设备上的信息

以下内容只保存在你的手机里，不会发送给我们：你的设置、保存的混音组合、定时与唤醒设置、收听记录与连续天数、钻石专属主题的选择，以及你自己添加的自定义助眠音（音频文件只存放在本应用的设备存储里，不会上传）。卸载本应用会一并删除这些数据。

权限说明

  • 通知：用于睡前提醒、渐入唤醒闹钟、续费提醒，以及后台播放时通知栏那条静音的"正在播放"通知。你可以随时在手机设置里关闭。
  • 后台播放（前台服务、播放期间保持设备唤醒）：用于在你锁屏或切换到其他应用后，白噪音仍能继续平稳播放；停止播放后即释放。
  • 网络：用于校验购买和下载场景视频。

本应用不会请求你的位置、通讯录、相机、麦克风、相册等敏感权限。

第三方服务

为了在 Google Play / App Store 内购场景下校验订单是否真实有效、管理订阅与会员到期时间，本应用使用了以下第三方服务：

  • RevenueCat（隐私政策）——负责校验你在 App Store / Google Play 完成的订单，并判断你当前的会员/订阅状态。RevenueCat 会处理你的订单信息（购买的商品、订单号、金额、到期时间）、一个由 RevenueCat 生成的、与你的应用商店账号绑定的匿名标识符，以及设备/App 相关的技术信息（如设备型号、操作系统版本、App 版本）。RevenueCat 不会收到你的姓名、邮箱、银行卡号等信息。
  • Firebase（Google 提供，隐私政策）——我们用 Firebase 的云函数和数据库服务，接收 RevenueCat 转发来的订单事件，保存一份会员状态记录，用于你更换设备或重新安装本应用后能找回会员资格，以及在你联系客服处理"已购买但未显示会员"类问题时核对。除了会员状态本身，我们也会原样留存每一条订单事件的完整记录（可能包含订单号、商品ID、金额、币种、购买所在的应用商店、国家/地区等 RevenueCat 随事件一起发来的字段）作为客服申诉/对账时的凭证，不会用来做广告或画像。这部分数据存放在我们自己名下的 Firebase 项目里，不会被用于广告或我们在本政策中说明以外的其他用途；云函数运行本身可能在 Google Cloud 的运行日志里留存请求方的技术信息（如 IP 地址），这是 Google Cloud 平台的默认行为，我们不会主动读取或用于识别用户。
  • GitHub（隐私声明）——部分场景视频没有打包在安装包里，你第一次打开该场景时会从 GitHub 的服务器下载，之后缓存在你的设备上。和任何网页下载一样，GitHub 会收到 IP 地址等常规技术信息，我们不会收到这些信息。

目前本应用不接入任何广告 SDK，也没有使用独立的用户行为分析/统计工具（如 Google Analytics）；如果以后接入，我们会在这里补充说明，并同步更新 Google Play 后台的"数据安全表单"，保持两处内容一致。
